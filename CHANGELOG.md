# Changelog

All notable changes to the "Strata Studio" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-26

### Added
- 100 curated color themes across 10 aesthetic categories.
- Live interactive preview canvas supporting Desktop and Mobile device views.
- Custom color editor with real-time WCAG AA/AAA contrast health analysis.
- Google Fonts catalog browser (1,950+ fonts supported via extension host IPC proxy).
- Export theme definitions to standalone HTML pages with CSS custom properties.
- Export to AI System Prompt Markdown specifications (`THEME_SPEC.md`).
- System clipboard integration via VS Code API (`vscode.env.clipboard`).
- Theme state persistence across sessions and window restarts using `globalState`.
- Keyboard shortcut `Cmd+Shift+T` (Mac) / `Ctrl+Shift+T` (Windows/Linux) to launch studio.
